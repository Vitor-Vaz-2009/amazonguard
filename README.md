# 🌳 AmazonGuard

**AmazonGuard** é um site desenvolvido como projeto acadêmico utilizando **HTML** e **CSS**.

O objetivo do projeto é apresentar uma empresa fictícia voltada para a proteção da Floresta Amazônica, promovendo a conscientização ambiental e a preservação da natureza.

## 🚀 Funcionalidades

* Página Home
* Seção de Parceiros
* Seção FAQ (Perguntas Frequentes)
* Logo personalizada
* Layout simples e intuitivo
* Navegação entre seções

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3

## 📸 Demonstração

Acesse o projeto online:

https://amazonguard.netlify.app

## 🌱 Sobre a AmazonGuard

A AmazonGuard é uma empresa fictícia criada com o propósito de proteger a Floresta Amazônica por meio de ações sustentáveis, educação ambiental e conscientização da população.

### Missão

Proteger a Amazônia e incentivar práticas sustentáveis para as futuras gerações.

### Valores

* Sustentabilidade
* Respeito à natureza
* Responsabilidade social
* Preservação ambiental
